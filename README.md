# Aswenna (අස්වැන්න)

Aswenna is a smart agricultural platform designed to empower Sri Lanka's farming community. It creates a digital bridge between farmers, landowners, and sponsors, promoting sustainable agriculture, financial transparency, and efficient resource management.

## 🌱 Overview

Aswenna (අස්වැන්න) is a digital agriculture platform that connects three key stakeholders in Sri Lanka's agricultural ecosystem:
- **Farmers (ගොවීන්)**: Access land, resources, and funding
- **Landowners (ඉඩම් හිමියන්)**: Efficiently utilize their land through collaboration
- **Sponsors (අනුග්‍රාහකයන්)**: Invest in sustainable agriculture projects

## ✨ Key Features

### 🔗 Unified E-Link System

### 🚪 Role-Based Sign-In

### 💰 Financial Transparency
- Investment tracking
- Revenue monitoring

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required - runs directly in the browser

### Accessing the Platform
1. Open `index.html` in your web browser
2. Select your preferred language from the dropdown
3. Watch the introduction video to learn about the platform
4. Click "Sign In" and choose your role:
   - Farmer
   - Landowner
   - Sponsor
